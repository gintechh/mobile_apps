### 📌 Overview
A multi-functional web application developed as a school project, integrating various interactive mini-tools and games in one place with a mobile-responsive interface.

### 🛠️ Included Mini-Apps:
* **🔮 Omikuji (Fortune Telling):** Random fortune generator based on traditional Japanese Omikuji. [Completed]
* **⏱️ Time Guessing Game:** A game testing players' sense of timing and accuracy. [Completed]
* **🧮 Calculator:** Tool for performing basic arithmetic operations. [Completed]
* **📝 Memo:** Simple note-taking tool for daily tasks and thoughts. [In Progress]
* **🎮 Mini Game:** Interactive web-based game. [In Progress]

### 🚀 Tech Stack:
* **Frontend:** HTML5, CSS3, JavaScript (Responsive Design)
* **Backend & Database:** Java, SQL
* **Tools:** VS Code, Git, GitHub

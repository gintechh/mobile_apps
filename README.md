### 📌 Overview
A multi-functional web application developed as a school project, integrating various interactive mini-tools and games in one place with a mobile-responsive interface.

### 🛠️ Included Mini-Apps:
* **🔮 Omikuji (Fortune Telling):** Random fortune generator based on traditional Japanese Omikuji.
* **⏱️ Time Guessing Game:** A game testing players' sense of timing and accuracy.
* **🎮 Mini Game:** Fun interactive web-based game.
* **🧮 Calculator:** Tool for performing basic arithmetic operations.
* **📝 Memo:** Simple note-taking tool for daily tasks and thoughts.

### 🚀 Tech Stack:
* **Frontend:** HTML5, CSS3, JavaScript (Responsive Design)
* **Backend & Database:** Java, SQL
* **Tools:** VS Code, Git, GitHub
